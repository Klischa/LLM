# Заметки и конспекты пользователя

## Проект "Мобильный LLM-ассистент"
- Дата: 2026-09-20
- Устройство: Infinix Note 30 (MediaTek Helio G99, 8 ГБ ОЗУ, 256 ГБ ПЗУ).
- Цель: полная автономность без отправки данных в облако.
- Решения:
  1. Архитектура модели: Qwen2.5-1.5B-Instruct с квантованием Q4_K_M.
  2. Инференс-движок: llama.cpp через JNI binding под Android ARM64-v8a.
  3. UI: Jetpack Compose с Material 3 и отображением ток/с в реальном времени.
  4. Ограничение потоков: `n_threads = 2` или `3` для предотвращения перегрева Cortex-A76.

## Встреча с командой бэкенда (22 сентября)
- Обсудили синхронизацию заметок через локальный WebDAV или p2p Syncthing.
- Безопасность: модель не сохраняет кэш на диск без шифрования (SQLCipher для локальной БД).
- Задачи:
  - Протестировать время холодного старта llama.cpp на Helio G99 (целевое время < 1.5 сек).
  - Собрать бенчмарк энергопотребления с помощью Battery Historian.
